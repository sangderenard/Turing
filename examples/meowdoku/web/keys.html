A key generated for you here controls access to encrypted files. A credential issued by another service can be stored or shared as an encrypted file, and remains valid until that service revokes it.

Your generated file key

Created in your browser for file encryption. Friends use its public half to encrypt files for you; your private half is never sent to them. The server stores a passphrase-encrypted recovery copy for a new device. Keep the recovery passphrase: losing it makes old encrypted files unreadable. The unlocked key stays in this page's memory only.

Alpaca-issued paper credential

Alpaca issues the ID and secret; Meowdoku does not generate or revoke them. Connect it to your own market page, store an encrypted copy, or share a recipient-encrypted copy with an accepted contact. Connecting a key lets Meowdoku's backend use its plaintext for Alpaca requests. A recipient can keep a copy after sharing, so revoke or rotate it at Alpaca if access should end.

Encrypt and store privately saves a file without connecting it. To connect it later, open My files, unlock the file, and choose Open on Keys page.
