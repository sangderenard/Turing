## Order
1. Confirm the server change is live; coordinate with other workers (HOW_TO_START.md section 4).
2. Move instances behind the proxy, bound to loopback with a route, one at a time with the session-preserving stop:
   `.\Stop-Meowdoku.ps1 -Port 8766` then `.\Start-Meowdoku.ps1 -Port 8766 -Route a -Bind 127.0.0.1`.
   (Optional second instance: `.\Start-Meowdoku.ps1 -Port 8768 -Route b -Bind 127.0.0.1` and uncomment the 8768 member + ProxyPassReverse.)
3. `.\Start-Apache.ps1` (runs `httpd -t`, starts httpd in the background, waits for :443, curls /api/whoami with the CA).
4. Verify with the checklist in APACHE_FRONT_2026-11-10.md (real client IP in instance log, Secure cookies, `/ws` 101, MEOWDOKU_ROUTE cookie,
   `/api/admin/lifecycle` not served via Apache). `.\Status.ps1` shows listeners and PIDs.
All scripts take `-WhatIf` and print the exact commands. `-Dev` on Start-Meowdoku.ps1 reproduces the 8767 dev line.

## Rollback
`.\Stop-Apache.ps1`, then `.\Stop-Meowdoku.ps1 -Port 8766` and `.\Start-Meowdoku.ps1 -Port 8766 -Bind 0.0.0.0` (add `-Route a`
only if the server accepts it). Public 8766 access returns once the listener is on 0.0.0.0.
