## Necessary ingestion/control changes

- SOURCE_RESOURCE_CONVERSION is published from the exact authored With before
  converting its body. Each generated scope declares its actual acquisition
  and cleanup occurrences in SOURCE_RESOURCE_SCOPE at graph-node ingestion.
  The admitted class is Condition, using the existing exact source API
  recognition. Mutex/custom With scopes are not silently admitted.
- Resource activity explicitly connects entry, body and finalbody cleanup.
  SOURCE_ACTIVITY_ARM_RELATION declares this ordered relationship. The audit
  still rejects edges between mutually exclusive arms; body-to-cleanup is
  accepted only with this declared resource-conversion proof on the edge.
- Early control ingestion builds an actual ResourceScopeBlock before carving.
  SOURCE_RESOURCE_CONTROL joins that placed block, the acquired/cleanup process
  operations and their exact captured receiver. Entry and cleanup must consume
  the same graph value. Late placement reads these cells, validates current
  operands, and posts its rewrite with the resource facts as causes.
- The source break case retained native loop10 but its shader analysis
  produced control_program=None with blocker 'no-shader-region'. That loop
  contains acquire/release and break work, even without numerical regions.
  SOURCE_LOOP_CONTROL_WORK now proves its actual process and exit work; the
  existing native loop composer retains and publishes the ControlProgram.
- Result-free resource cleanup is a source visibility contract, not permission
  to omit the registered process operator's SSA result. Every cleanup occurrence
  gets a private, fresh None/status value via RESOURCE_CLEANUP_RESULT, derived
  from its process/control/argument identities. This avoids duplicated source
  result identities across exit edges and satisfies the unchanged result audit.
- Acceptance projection and read-scope copying retain the new semantic pages.
  Audits validate conversion origins, endpoint contracts, receiver provenance,
  ordered arm proofs, and region-less loop-work proofs. No bypass/xfail added.
