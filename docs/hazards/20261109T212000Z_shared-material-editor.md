# Shared selected-material editor

User prioritized using the existing bottom Edit layer material selector for every simulation's properties. The optical controls now filter to that selected material instead of listing their own independent material set. IOR is edited only through the existing PBR Index of refraction control; capture reads that same row. Importing an existing optical profile copies its already-authored IOR into the editable shared PBR view without rewriting saved object files. Injection mode visibly states that it uses host IOR; non-volume materials receive an unsupported-volume notice. Spectral transmittance/reference thickness/concentration remain authoring inputs to the existing native extinction adapter, not a new material identity. The three modes and saved spectra remain available.

Published targeted mainJS context/refresh hooks, optical module and HTML wording; HTTPS hashes verified. Node tests cover selected-material filtering, no duplicate IOR editor, shared PBR IOR capture, unsupported-volume state, all mode restoration and immutable save/load. No server restart.
