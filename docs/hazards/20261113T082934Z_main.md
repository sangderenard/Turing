Owner decision (2026-11-13): per-call-site keys -- each call site's copy of a method is keyed on the literal values
the caller's object holds in the fields that method reads, so each geometry compiles as its own kernel with the
other shapes' branches removed. The bitmask bake must end up native and performant (not yet reached; see below).

What changed:
- Receiver-field keys. topological_reducer: a call names `call_receiver_field_state_cells` (the field-state cells,
  WRITTEN/MERGED, current at the call for every object it passes that no earlier call may store into, no loop
  open); a read of a formal's field with no prior write/storing call/loop is `entry_field_read`. glsl
  `_callsite_specialized_shell_type`: the fields a callee reads at entry and never writes (`_entry_field_reads`)
  are keyed by the caller's literal (`_caller_receiver_field_literals`, identity join `_node_names_identity`);
  posted as PLANNER_RECEIVER_FIELD_SPECIALIZATION (new page, CONCORD, DERIVED from the caller's field-state,
  value and proven_literal cells), in the copy cache key, the numeric scope receipt (`field:<formal>.<field>`)
  and the symbol contract (fortran_c_shell `receiver_fields`). The fold reads an entry read as the key's
  literal; field-literal rules now precede the declared record field's type fact.
- PRE-EXISTING fixed: SOURCE_CONTROL_SPECIALIZATION was keyed by function NAME, so two copies of one function
  deciding an If oppositely read each other's arm: `offsets(2, 3)` beside `offsets(1, 3)` refused "node 7 is
  resident in the rejected orelse" on clean 2716cd06. Now keyed by the deciding graph's read scope (one per copy).
  c795 / c884 move from that refusal to later emission gaps.
- PRE-EXISTING fixed: an `if` arm ending in an authored `raise` was not terminal once exception ingestion spelled
  it as an `exception_raise` call, so `if g == 1: x = 3 else: raise ...; x * 2` lost `x` (external input,
  "region value ... has no settled dtype") on clean main. terminal_branch now reads the call's
  SOURCE_EXCEPTION_OPERATION receipt (`exception_raise`), as the reducer's two other raise readers do.
  LLVM PASS for if/raise, if/elif/raise and a method form. FORTRAN: EMIT-INCOMPLETE (ExceptionNone/ExceptionMake
  have no Fortran lowering) -- separate gap, not traced.
- Field reads in arms: two arms that only observed a field (or a live arm that only observed it) no longer mint
  a MERGED / ARM_SELECTED version; the field's state after the conditional is its state before. (YoungMan
  `define_offsets`: every geometry arm reads `dtype=self.precision`; the merged "write" disqualified the
  single-write transfer.)
- Audit: a receiver-field key must cite the caller's field-state cell.
