# Structured original GLSL traversal ingestion (staged, Windows)

`src/compiler/glsl_control_ingestion.py` reads supplied original GLSL function
text into existing typed SSA arithmetic, CFG/Phi, GetElementPtr/Load/Store,
and fixed local integer-array Const instructions. Source helper calls are
inlined with real early-return and inout/out state. Logical operators preserve
short-circuit effects. There is no handwritten traversal or intersection law.

The complete composed `nearest_filtered` source is retained. Triangle-candidate
builds explicitly specialize `boundary_only=false`, `uStudioSphereCount=0`, and
`studio_region_filter=-1`; zero-trip/constant-branch pruning uses those inputs.
Sphere competition and subsequent transport remain in the server continuation.
Node and TriGeom storage retain all 12 and 16 float32 slots respectively.
Original left-then-right pushes, right-first pops, leaf ID order, strict distance
comparison, and scale-sensitive region epsilon are unchanged.

The source root, specialization constants, record/storage/uniform layouts,
SSA values, blocks, and exact control edges are published in the concordance.
The common audit reparses the original signature and compares specialization,
storage layout, argument types and merged outputs with their source record.
Corruption tests detect changed specialization and buffer capacity. Tests audit
before and after Wasm emission. Unknown reachable calls, unsupported
types/layouts, and shadowed local declarations fail closed. This is a bounded
GLSL frontend, not a general GLSL compiler. Existing WebGPU lowering does not
support the resulting nested CFG and indexed mutable storage; no full-traversal
WebGPU execution or SIMD claim is made here.

Observed focused verification:

- `python -m pytest tests/test_glsl_control_ingestion.py`: 8 passed in 2.00 s.
- Combined new structured, existing scalar source, and existing AST ingestion:
  17 passed in 2.77 s with source-record corruption audit and final
  monotonic-block-label/condition checks.
- Actual composed source on a three-node/two-triangle fixture chooses the right
  child for equal distances. Reversing same-leaf IDs changes the retained tie
  winner accordingly. An empty node range returns -1 and float32 1e30.
- At world x=100, actual region epsilon rejects a hit at 5e-6. Changing only
  supplied epsilon-helper source to 1e-12 makes the compiled traversal accept
  it, proving the emitted computation follows that source rather than a fixed
  substitute.
- Nested loops, local stack indexing/increments, continue, break, helper inout
  effects, and unreachable-specialized calls execute in the common Wasm lane.

The integration owner separately measured the saved 95,217-triangle,
65,535-node, 256-ray stage fixture through one compiled batch call: all triangle
IDs match the saved GPU result; maximum distance delta 1.49e-8. Their build is
`examples/meowdoku/studio_traversal_compute.py`; retained products are under
`build/dot-client-ray-20261109/studio-region-compute/`. No service restart,
deployment, browser action, or repository publication was performed here.
