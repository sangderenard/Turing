Direction (owner, 2026-11-12): a tensor is a handle and a data region; the caller provides all memory a call needs;
the saved content carries the handle, and a stride tuple may override its layout, with enough information to infer
the total length the caller allocates.

Added to src/common/tensors/compression/tensor_payload.py (Python API the compiled host call will serve):
- `read_handle(path_or_payload)` -> (dtype, shape), read from the uncompressed handle record without decompressing
  the region.
- `c_strides(shape)`; `region_length(shape, strides=None)` = 1 + sum((extent - 1) * stride) (0 when empty): the
  elements the caller provides for the saved C order or for its own stride tuple (in elements, one per axis).
- `load_into(path, region, handle, strides=None)` -> status, the shell's `utf8_sequence` convention: 1 complete,
  2 over capacity (region shorter than region_length, or handle shorter than 1 + 2 * rank; nothing written),
  3 failed (unreadable, region dtype is not the payload's, stride tuple of another rank). The caller's int64 handle
  buffer receives `rank, *shape, *strides`.
