2026-11-11 REVIEWED CHANGES, BRANCH CLEANING, THE REST INDEX (MEASURED off-line; NOT LIVE, examples/meowdoku):

What exists now.
- `branch_review.py`: `branch_reviews`, `branch_review_remarks`, `branch_merged_seen` in the accounts database.
  One rule, `standing`: an admin's decision settles a change; without one, a change nobody objects to is accepted
  when its time-out passes; one standing objection stops the clock until an admin decides. Decisions and landings
  name the commit. `http_route` serves `/api/reviews` (list, submit, remark, decide, withdraw) and the open
  `/api/reviews/standing?repository=&head=` that answers only accepted true/false for one commit.
- `branch_gate.py`: the only place that runs Git for reviews. `land` is fast-forward only and never forces; `clean`
  removes a branch only when all of it is on the remote default branch, the cleaner first saw that at least
  `grace_days` ago, and it is not protected, not checked out in any worktree and not kept by its review. Removal is
  by expected commit on both sides. `check-push` / `install-hook` is a local pre-push check (not installed).
- `deploy/branch_policy.json` (apply=false: report only), `deploy/review-gate.yml` (the GitHub required check; it
  asks `/api/reviews/standing`), `deploy/Protect-DefaultBranch.ps1` (the GitHub rule; not run).
- Task worker: `reviews.land` and `branches.clean` (cron.table lines added to the deploy copy only).
- `/api/index`: the declared REST catalog of speaktome (`speaktome_api/catalog.py`), dispatched by the server.

Measured. `tests/test_meowdoku_branch_gate.py` 14 passed (real temporary Git repositories, real SQLite, a real
refused `git push` through the installed hook); with `test_meowdoku_scheduled_tasks.py` 22 passed, 1 skipped. Dry
run of `clean` over the five policy repositories with a scratch ledger: 151 branches, 0 removed today, 57 would be
removed once merged for 14 days, 94 kept (44 with commits of their own, 39 checked out, 11 protected).
