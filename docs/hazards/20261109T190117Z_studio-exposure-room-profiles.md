# Exposure and Room lighting profile separation

A (exposure) is authoritative for photo/live ray inputs. B (room) follows A by default; individually unlocked settings affect Phong only. This applies to captured light strengths/filters/poses, studio surface controls, backdrop layers, table, scale, and gobo properties. Topology creation remains in A; B can override existing instances. Stable gobo/pose IDs prevent overrides moving onto a different instance after deletion. C/D retain free complete-profile configurations. Prior A/B snapshots remain accessible rather than discarded. Legacy split-strength profiles migrate without changing their actual exposure/room levels.

B solo is Phong-only; A solo propagates unless B solo is independently selected. Calibration temporarily follows A and clears transient solo, restoring Room override data in finally. Room edits do not invalidate or restart live rays. Named profiles and C/D save both channels; this does not introduce automatic server persistence.
