## Implemented

All six ingested Condition operations now reduce to primitive SSA. Wait and
notification have real CFG bodies in condition_ssa.py, using the incumbent
control builder and synchronization receipt writer. No opaque Condition
instruction remains in the tested modules or emitted source calls.

- Default construction allocates its recursive mutex/empty waiter state.
  Supplied Lock/RLock construction allocates a distinct WaitQueue referring to
  the exact guard. Two Conditions sharing a lock retain different queues.
- Wait validates ownership, creates/registers a retained latch before unlock,
  saves/releases full recursion depth, parks with explicit timeout mode,
  reacquires/restores, retires and destroys. Failure paths avoid parking after
  failed setup. Status, ownership and retirement Phis encode the joins; actual
  effect dependencies join restore->retire->destroy.
- Notify(n) is an SSA count-Phi/select/signal/decrement loop. Notify-all traverses
  until no pending waiter remains. Neither releases the guard or creates an
  all-participant barrier. Negative/zero/None timeout distinctions are retained.
- Acquire/release use the existing mutex/token protocol. Every projection has
  SOURCE_SYNCHRONIZATION/SSA_SYNCHRONIZATION identity, explicit scopes and
  release/acquire operands. Leaf control operations request no memory fence.
- SSA_SYNCHRONIZATION_PROCEDURE records exact source, entry/exit blocks,
  primitive receipts, outcome identity and CFG edges. The audit reads it and
  the C selections. Unused pure outcome materializations may be reduced away;
  their typed identities remain in the concordance. No audit exemption added.
- The existing native Condition state engine was factored into mutex,
  waiter-queue and latch primitives in turing_pool.c. Historical Condition/Event
  ABI procedures delegate to the same state/primitives; no second engine,
  Python executor, object registry, general deque substitute or manager thread.
- The existing native thread scope also owns sync allocations, with child joins
  preceding parent resource disposal. Latches retire during each wait. Escaping
  handles require ownership transfer and are explicitly refused. Source worker
  context tokens reuse the existing management-instance counter, installed at
  dispatch, with a disjoint legacy-caller encoding; no hardware lane is selected
  in SSA. Counter exhaustion refuses creation instead of recycling an identity.
- Runtime errors use existing native records/shell channel. Protected calls
  capture failures without fabricating scalar temporaries for discarded results.
  Standard Condition/Lock/RLock resource recipes use the existing resource IR.
  Try can surround a resource; cleanup failures and protected returns are handled.

Native host timeout checks reject invalid/overflowing values. Linux uses the
monotonic condition clock; deadlines round upward. Windows uses QPC deadline
calculation and native parking, but Windows execution was not measured here.
Native mutex transitions implement the declared acquire/release orders; other
ordering/memory-class requests are refused, not reinterpreted.
