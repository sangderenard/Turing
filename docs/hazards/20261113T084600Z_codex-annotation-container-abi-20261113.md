# Constructor return source evidence is not ownership transfer

An ordinary returned record descriptor previously depended only on its field value. The exact constructor which assembled that record was absent from its provenance. Record registration now retains the source constructor cell, available ordered operand receipt, and field declaration cells alongside the incumbent member sources.

The new read-only source_owned_record_returns reader joins an explicit keyword constructor operand to the exact returned sequence descriptor and real record return slot. It requires the record descriptor to descend from that constructor, not merely have the same numeric id. Missing keywords, a mismatched field source, or a return slot naming another value do not authorize a match. Positional constructors are deliberately not guessed. The result is source evidence only: no ownership-transfer, public-result, cleanup, or native-lifetime permission is published.
