# Opt-in Nodus/client first-hit job bridge

Source-ready bounded slice, not a distributed renderer or a general queue. Newly created jobs may opt into client_intersections only for one fixed:3 still at 128/256 longest-edge pixels. Live and larger requests reject explicitly. Nodus owns the actual native loan/FIFO/receipt; Python HTTP transports payloads and existing server authentication. Compiled first-triangle law runs on the participant's WebAssembly backend. Spheres, partition selection, material regions and later spectral transport remain authoritative on the GL worker. Returned work receives 1:1 verification before continuation; no estimator work is duplicated as an unreported fallback.

PhotoJobs binds immutable job ownership, creates separate ephemeral worker and browser credentials, and passes only the worker credential through child environment. Secrets are not included in saved config, command lines or profile/status reports. Engine mailbox is loopback-only, rejects Origin headers and authenticates before bounded body reads. Browser join/relay requests require existing owner identity, matching origin and HTTPS except local development loopback. Join never creates a job. Process exit/cancel invalidates enrollment; a status/readiness sweeper removes stale credentials.

Scene-once transport sends exact packed triangles, owner IDs and BVH descriptor keyed by revision, geometry hash and composite query law. A browser acknowledges successful installation before subsequent strips omit geometry. A device without resident data can request the descriptor again. Bounds: 200,000 BVH triangles, 400,000 nodes, 64 MiB scene upload, 4,096 rays per protocol packet and 2 MiB ordinary request body. Initial worker batches are <=256 rays. Original displayed WebGL meshes are not presumed identical to the authoritative stage pack.

Readiness credits come from explicit participant polling, and are consumed by publish. The GL worker waits for fresh readiness before starting a 60-second ray lease, so a user's duty-limit rest or hidden tab does not become an intentional data loss. Expiry retains/reoffers the exact original strip; cancellation is explicit. Received/submitted does not mean committed. Uncertain responses are polled, not blindly resent. Scene/kernel changes invalidate caches. Reloaded pages have an explicit owner-scoped Participate / resume action.
