2026-11-10 ISLAND DOOR IN A REAL BROWSER PAGE: THREE DEFECTS FOUND AND FIXED; DEMO WORK STOPPED (MEASURED, local Windows, main 6a2e4b19 + working tree):

`tools/build_living_island_demo.py --out build/living-island-demo` projected two pages (outside world with one lot;
that lot's island as its own world): first page 437.4 s, second 29.2 s, about 15.0 MB each. Opened through the live
site in the app's built-in browser.

Observed in the page, each invisible to the function-level checks that already passed:
1. A fresh visitor got NO door sheets. `restoreLivingEdits` returned before `migrateLegacyPortalOpenings` when no saved
   payload existed. Fixed: every exit of the restore function converts declared portal openings. After a rebuild the
   outside page showed both sheets (enter:in with island and href, exit:out) with no console error.
2. Crossing the lot's sheet (walker position set on either side, the game's own `updatePortalTraversals` called) moved
   the browser to `living_island_inside.html#arrive=<pair>`, but the outside page threw
   `Issued action names an unknown edge: undefined` on each frame: the action timer refuses an issued action without a
   registered edge. Fixed: `leaveThroughIslandDoor` registers its edge.
3. On the island page the arrival was consumed only after the vehicle qualification gate closed (the entity cycle does
   not run during it), and the walker, seated in the vehicle by that gate, was carried back to the vehicle on the next
   cycle. Fixed: a walker seated in the vehicle arrives on foot.
`node tests/abstract_ui_island_door_check.mjs` covers all three and passes. Fixes 2 and 3 were NOT re-verified in a
browser: the second rebuild was stopped.

Why stopped: the owner's verdict is that the demo site is the problem (the page that binds world rules into the
document), that the engines are solid and need other solid engine parts, and that this page is history. The door and
island crossing code in the browser template is a prototype; the declarations on the Python side (openings, pairs,
doors, island documents) are the part to keep. The two demo pages remain in the web folders, unlinked, built before
fixes 2 and 3.
