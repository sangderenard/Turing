Record ABI materialization later revises the descriptor to uint32 but cannot rewrite the already minted int64 SSA column.

Focused c626 uses the same authored array field and append from `list[int]`. Before repair it lowers through the canonical entry, then fails `assert 'int64' == 'uint32'` for the SSA column. The SSA builder reads that contract before minting the receiver column. A checked int64-to-uint32 conversion at append verifies `0 <= value <= 0xffffffff` before passing the typed helper; invalid values signal the existing validation runtime instead of silently wrapping.
