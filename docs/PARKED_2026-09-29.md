## 5. Compiler housekeeping found along the way
- Multithreading audit: only `zig cc` piece compilation is simply
  parallelizable; ABI settlement refolds every graph every round — a
  per-graph digest memo, not threads. The identity book is a contextvar with
  unlocked dicts; threads would silently drop writes.
- `control_source.project_control_regions` keeps every validation guard;
  dropping a guard whose predicate was projected away must go through the
  concordance, not a set test.
- `fortran_c_shell.compile_fortran_module_c_shell` uses `shutil` without
  importing it (unused by the Woodshop path).
- Temporary diagnostics still in the tree: `temporary_woodshop_descriptor_trace`
  (glsl_deployment_strategy.py), `TURING_DEBUG_SEQUENCE_RECORD_ABI` block
  (fortran_c_shell.py). Remove before the final Woodshop commit.
